06 — THE CURVEBALL FIXTURE: A REPOSITORY STATIC ANALYSIS CANNOT FULLY RESOLVE
================================================================================

This is the artifact for curveball requirement 5. It is a real repository, not
a mocked snapshot, built so the path from a test to a production symbol runs
through dynamic dispatch that cannot be resolved statically.

Why the hop is genuinely unresolvable, not just unresolved by luck:
  - Gateway has TWO implementations (Stripe, Adyen), so the provider's rule
    "interface method call resolved to the unique implementing method" cannot
    fire (internal/sem/provider.go:8459).
  - `Charge` is not a globally unique method name either, so the name_only
    fallback ("method call matched globally unique method name") cannot fire.
  - So `g.Charge(cents)` in Checkout has no resolvable target. The graph holds
    no edge across it.

The fixture source is committed as a Go test fixture in
internal/cli/simulate_test.go (TestSimulateOnUnresolvableDynamicDispatchFixture).

--- RECIPE: REBUILD THIS FIXTURE FOR A LIVE DEMO ---

The fixture is committed as a Go test (it builds itself in a t.TempDir), so for
a live demo make a scratch copy:

  mkdir -p /tmp/dispatch-fixture && cd /tmp/dispatch-fixture
  git init -q . && git config user.name t && git config user.email t@t.local
  printf 'module fixture\n\ngo 1.21\n' > go.mod

  cat > payments.go <<'EOF'
  package app

  type Gateway interface {
          Charge(cents int) error
  }

  type Stripe struct{}

  func (s Stripe) Charge(cents int) error { return chargeViaStripe(cents) }

  type Adyen struct{}

  func (a Adyen) Charge(cents int) error { return chargeViaAdyen(cents) }

  func chargeViaStripe(cents int) error { return nil }

  func chargeViaAdyen(cents int) error { return nil }

  func Checkout(g Gateway, cents int) error { return g.Charge(cents) }

  func FormatAmount(cents int) string {
          if cents == 0 {
                  return "free"
          }
          return "paid"
  }
  EOF

  cat > payments_test.go <<'EOF'
  package app

  import "testing"

  func TestCheckoutWithStripe(t *testing.T) {
          if err := Checkout(Stripe{}, 100); err != nil {
                  t.Fatal(err)
          }
  }

  func TestFormatAmount(t *testing.T) {
          if FormatAmount(0) != "free" {
                  t.Fatal("bad")
          }
  }
  EOF

  git add . && git commit -qm fixture

  # ground truth
  go test ./... -run TestCheckoutWithStripe -coverprofile=cov.out
  go tool cover -func=cov.out

  # our tool
  cd <deathcode> && ./entire-graph simulate --repo /tmp/dispatch-fixture --symbol chargeViaStripe

NOTE ON INDENTATION: the heredoc bodies above are indented for readability in
this document. Go does not care, and gofmt is not run on the scratch copy.
