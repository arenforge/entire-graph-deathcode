SECTION D6 — WHICH RESOLUTIONS ARE ACTUALLY CONFIRMED, READ OFF THE PROVIDER
================================================================================

The partition below is not our invention. It is the provider's own Reason
string for each Resolution value, read at internal/sem/provider.go and the
per-language relation builders:

  exact            "direct call expression resolved to ..."            CONFIRMED
  import_resolved  "resolved through import qualifier to defining ..." CONFIRMED

                    symbol" / "... same-directory symbol"              CONFIRMED
  type_inferred    receiver type inferred, not declared                NEEDS FLAG
  name_only        "matched globally unique symbol name",
                   "method call matched globally unique method name"   NEEDS FLAG
  pattern          "route-like string literal found inside handler",
                   "near-duplicate symbol body (MinHash estimate)",
                   "event/channel name detected by emit/listen pattern" NEEDS FLAG
  import_external  target is "external:symbol:*", outside the repo     N/A here
                   (already dropped at internal/cli/simulate.go:284)

receiver's type could not be established, so the edge was drawn because exactly
